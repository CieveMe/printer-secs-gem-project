# 本地验证指南

## 1. 环境和配置

- Windows 10/11 x64
- Visual Studio 2022 或 .NET 8 SDK
- 客户机需要 .NET 8 Desktop Runtime x64

正式项目文件为 `PrinterSecsGem.sln`。现场配置入口是程序目录下的 `App.config`；`appsettings.json` 只作为源码默认配置和本地开发参考，不能覆盖现场配置。

`Runtime:Mode` 可设为 `Unit`、`Server` 或 `Both`。真实联调时按现场 Host、COM 号、Sensor 模式和 Zebra 地址配置。

## 2. 构建和协议回归

在仓库根目录运行：

```powershell
& dotnet build .\src\PrinterSecsGem.Eq\PrinterSecsGem.Eq.csproj -c Release --no-restore
& dotnet run --project .\tests\PrinterSecsGem.Eq.ProtocolValidation\PrinterSecsGem.Eq.ProtocolValidation.csproj -c Release --no-restore
```

首次构建需要按 `NuGet.Config` 完成还原。当前 v1.0.8 协议验证已通过 17 项。

## 3. 本地模拟验证

不连接 Host 时可运行：

```powershell
& dotnet run --project .\src\PrinterSecsGem.Eq\PrinterSecsGem.Eq.csproj -- --validate-local
```

模拟验证包括 RFID 写入/查询、ZPL 生成、日志写入和事件组包，但不能替代真实串口、Sensor、点阵屏、Zebra 或 Host 联调。

## 4. SECS/GEM 测试顺序

使用 `samples/secs/PrinterSecsGem-UI-SECS-Test.SMD` 或等效模拟器：

1. `S1F1 -> S1F2`：确认 `ERACK` 和真实版本。
2. `S1F13 -> S1F14`：确认 COMMACK `00` 和设备信息。
3. `S5F11 -> S5F12`：确认成功、格口不存在、读取失败及结果描述。
4. `S8F3 -> S8F4`：确认打印成功、离线、缺纸和内容为空结果。
5. `S10F3 -> S10F4`：确认正常显示、空字符串清屏、格口不存在、错误 Item、不可打印字符和超长内容。
6. `S10F11 -> S10F12`：确认正常写入、空 RFID 格式错误、格口不存在和硬件失败。
7. 观察事件：格口状态变化为 `S6F21`，RFID/打印结果按当前定义发送 `S6F11`。

## 5. Sensor 与 RFID

`PresenceMode=Sensor` 且功能启用时，写入成功后回读一次，以实际写入长度 N 精确比较原始字节，包括尾部空格；一致后刷新显示。回读失败或不一致不得刷新显示，并返回失败码、描述和 `CE2005`。

`PresenceMode=RfidPolling` 是传感器异常时的临时路径，由后台轮询维护缓存；S5F11 读取缓存，不增加即时读卡，写入也不增加同步回读和显示操作。

验证含尾部空格的 RFID、回读一致/失败/不一致、显示失败，以及轮询模式不产生额外同步读卡。

## 6. MES RFID 输出

对外 RFID 只保留 ASCII 英文和数字：

```text
Abc123_测试!@#XyZ789 -> Abc123XyZ789
ABC 123              -> ABC123
测试!@#              -> A("")
```

确认 `S5F12`、`S6F21`、RFID 读写结果 `S6F11` 均过滤；硬件写入、回读校验、缓存和原始 HEX 日志仍保留原始值。

## 7. 发布和现场更新

发布单文件 EXE：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\publish-exe-only-win-x64.ps1 `
  -OutputPath .\publish\exe-only-<功能>-v<版本>
```

发布目录必须只有约 2 MB 的 `PrinterSecsGem.Eq.exe`，并检查文件版本和 SHA256。客户更新时退出程序、备份旧 EXE，只替换 `PrinterSecsGem.Eq.exe`；保留现场 `App.config`、日志配置、Zebra SDK 和其他运行文件。

## 8. 日志和反馈

默认日志为 `logs\\printer-secs-gem.log`。现场反馈应包含版本、实际配置键（隐藏敏感地址）、完整日志、测试时间、Host 报文或截图、硬件现象和期望/实际结果。日志可以证明记录到的技术行为，不能单独证明未记录的屏幕效果或客户验收。
