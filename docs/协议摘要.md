# 电子货架 SECS/GEM-HSMS 协议摘要

当前实现版本：`v1.0.8`。仓库内的 20260306 PDF 是历史原始资料；本页描述当前代码已实现且客户已确认的协议边界。

## 角色与基础消息

| 消息 | 方向 | 当前行为 |
| --- | --- | --- |
| S1F1 W / S1F2 | Host -> EQ / EQ -> Host | 返回 `ERACK` 和真实软件版本 |
| S1F3 W / S1F4 | Host -> EQ / EQ -> Host | 查询状态变量 |
| S1F13 W / S1F14 | Host -> EQ / EQ -> Host | COMMACK `00`，返回 `ERACK` 和真实软件版本 |
| S5F1 / ALID | 不实现 | 按客户确认不实现报警消息 |

## 业务消息

### 查询格口状态

`S5F11 W -> S5F12` 查询货架/格口状态。`S5F12` 返回货架号、格口列表、RFID、有无货状态、结果码和结果描述。

结果码：`0` 成功，`1` 格口不存在，`2` 读取失败。

`RfidPolling` 模式下使用后台轮询缓存，不在 S5F11 请求中额外触发读卡。

### 事件上报

格口上架/下架状态变化使用 `S6F21`。RFID 读取结果事件、RFID 写入结果事件和打印结果使用 `S6F11`。

写入成功主动事件为 `S6F11 CE2002`，写入失败或回读校验失败为 `S6F11 CE2005`。

### 打印

`S8F3 W -> S8F4` 执行 Zebra 打印并返回结果；打印完成/失败通过现有打印结果 `S6F11` 上报。

### 设置点阵屏

`S10F3 W -> S10F4` 设置或清空指定格口的点阵屏。请求必须包含三个 ASCII Item：货架号、格口号、显示内容；显式空字符串表示清屏。

结果码：`0` 为 `Set Success`，`1` 为 `Location Not Found`，`2` 为 `Display Content Format Error`。其他硬件或路由失败使用自定义码，并在描述中明确原因。显示内容只允许 printable ASCII，超长或格式非法不静默截断。

### 设置 RFID

`S10F11 W -> S10F12` 向指定格口写入 RFID。空 RFID 按格式错误处理。Sensor 模式写入成功后回读一次，以实际写入长度比较原始字节，校验一致后刷新点阵屏。

`S10F12` 结果码 `0/1/2` 分别表示成功、格口不存在、RFID 格式错误；未枚举的硬件或校验失败可使用自定义码，并在描述中说明原因。

## RFID 输出边界

发往 MES 的 `S5F12`、`S6F21` 以及 RFID 读写结果 `S6F11` 中，RFID 只保留 ASCII 英文大小写字母和数字。过滤为空时仅返回空 RFID 字段，不改变有无货状态、结果码或事件类型。

硬件写入、Sensor 回读校验、轮询缓存和原始日志保留原始 RFID（包括尾部空格）。显示屏沿用独立的显示处理规则。

## 当前仍需外部确认

- 现场是否已完成 v1.0.8 实机验收。
